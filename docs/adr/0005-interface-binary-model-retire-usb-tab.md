# 通信接口为串口/网卡二元模型，USB 不再以独立页面存在

Status: accepted

旧导航把串口通信、USB通信、网络通信并列为三个页面，后两者实为占位空壳（合计约 120 行"功能开发中"）。决定合并为单一"接口通信"页，通信接口类型仅串口与网卡两类，网卡下再分三种接口协议（见 CONTEXT.md 术语），USB 占位页、导航项与状态栏槽位一并删除。未来若做 USB 调试（CDC/WinUSB 等），应作为第三种通信接口类型或串口的一种传输回到接口模型内，而不是恢复独立 tab。理由：按传输介质分页面是占位时代的假象；域的不变量是"选中一个接口、切换其参数配置"，两级选择（接口 → 网卡协议）已能容纳介质扩展。

## Considered Options

- 保留 USB 页占位等未来填充：与统一域并存两个空壳入口，且状态栏槽位索引将随未来的页面增删再度整体错位。

## Consequences

- 状态栏服务槽位与导航索引按"接口通信/工具箱/CH34x调试/固件升级/协议编辑"新集合重排。
