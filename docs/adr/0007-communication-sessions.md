# 按连接划分通信会话与历史

状态为已被 [ADR-0008](0008-session-owned-communication.md) 取代。

接口通信首先采用共享会话模块，页模块对每个已订阅连接最多拥有一个会话。会话模块管理分组布局、数据视图、历史与定向收发 API，业务页决定控件的放置。通信内核继续独占物理连接、发送资格、写入队列和协议任务通道。

订阅后页内按连接缓存有限的最新原始数据。会话打开时从当前游标开始记录，接收原始数据和底层确认写入的字节共同进入该会话的有界临时历史。标签失焦与布局变化不影响记录。关闭会话停止相应任务、删除临时历史并保留订阅，显式导出的文件由用户保管。记录与实时显示独立推进，缓冲覆盖或文件写入失败时明确提示数据缺口。

## 历史与恢复

页内缓冲按连接隔离，默认每连接最多 2 MiB，整页最多 8 MiB。每个打开会话另有 2 MiB 待写队列和 16 MiB 分段历史。回看按页读取原始记录，格式和显示设置由数据视图应用。达到容量上限时轮换最早的历史。磁盘写入失败时实时收发继续，会话显示原因并可恢复记录。

会话布局与显示设置独立持久化。重启恢复布局时从新历史开始，并清理上个进程遗留的临时文件。导出格式为 JSON Lines，保存收发方向、时间、原始字节和可用的来源信息。

## 与既有决定的关系

[ADR-0006](0006-global-communication-management.md) 的页级批量接口继续为现有调用提供能力。接口通信的用户操作与日志按会话定向处理，固件升级等业务页可在自己的控件中调用会话 API。
