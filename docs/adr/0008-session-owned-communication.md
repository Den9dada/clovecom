# 通信会话直接管理连接

状态为已接受，取代 [ADR-0006](0006-global-communication-management.md) 和 [ADR-0007](0007-communication-sessions.md)。

接口通信工作台统一负责连接配置、连接启停、数据收发和协议任务。一条通信连接对应一个会话，标签和右侧会话列表面向同一个配置。工具箱、CH34x 调试和协议编辑有各自的业务入口。串口文件传输与 Lua 固件升级在会话内运行。

运行时为每条连接保留有界写入队列和链路轮次。会话记录原始接收包和底层确认写入的字节，协议任务并行读取本连接的输入，独占本连接的发送通道。关闭标签会停止本会话任务、断开连接、清理临时记录，并保留会话配置。工作区支持在保留标签和草稿时单独断开连接。

启动时读取旧版连接配置，并在配置有效时迁移到只保存连接定义的版本。恢复已持久化的会话布局与显示设置。恢复的连接初始处于断开状态，会话历史从新记录开始。
