# 领域文档

本仓库采用单一上下文，领域术语位于根目录，架构决定位于 docs/adr/。

## 读取顺序

探索代码、设计模块或撰写规格前：

1. 读取根目录 GLOSSARY.md 中的新领域术语。
2. 读取根目录 CONTEXT.md 中保留的既有领域术语。
3. 读取 docs/adr/ 中与当前工作相关的决定，注意接受状态和取代关系。

文档尚不存在时继续探索，不预先创建空术语表或空 ADR。

## 使用与维护

- 输出、规格、测试和设计使用术语定义中的名称。
- 新增术语记录到 GLOSSARY.md；既有术语在当前定义来源维护，避免重复定义。
- 本次保留 CONTEXT.md，兼容现有引用；后续统一术语时迁移定义并更新引用。
- 术语表只记录领域概念，实施细节放入设计文档或 ADR。
- 方案与既有 ADR 冲突时，明确指出冲突范围和变更理由。
- 不以编号较新为由默认废弃旧决定，按明确的取代关系判断。
