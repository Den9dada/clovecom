# CloveRTLS GUI 设计参考包

整理日期：2026-10-15。用途：把当前项目的 GUI 风格、组件与交互规则交给其他项目作为设计和实现参考。

## 阅读入口

| 文件 | 用途 |
| --- | --- |
| [GUI 设计风格与样式规范](gui-style-reference.md) | 完整说明：风格、令牌、布局、组件、交互、六个页面、迁移与差异 |
| [设计令牌 JSON](design-tokens.json) | 供其他技术栈读取的颜色、尺寸和字体快照 |
| [设计令牌 CSS](design-tokens.css) | Web 项目可直接引用的变量；不包含完整组件实现 |
| [令牌导出脚本](export-design-tokens.ps1) | 从当前 Flutter 主题重新提取颜色、间距、圆角、字号和窗口尺寸 |
| [截图索引](screenshots/README.md) | 实现截图及其验证边界 |

## 如何交给另一个项目

复制整个 `docs/design/` 目录。先阅读规范，再使用 JSON 或 CSS 建立目标项目的语义令牌和基础组件。需要复用 Flutter 代码时，按规范中的依赖说明迁移共享控件；此参考包本身不包含组件源代码和字体文件。

可直接使用下面这段需求说明：

> 请参考本目录的 `gui-style-reference.md`、`design-tokens.json` 和实现截图，为本项目建立浅色、品牌紫色、细边框、紧凑信息布局的桌面 GUI。使用 MiSans 普通字体和等宽数字字体；普通动作高 28、行内动作高 24、控件圆角 6、卡片圆角 8、弹窗圆角 12。统一默认、悬停、按下、焦点、选中、禁用、错误和忙碌状态；主要动作、次要动作、图标动作与危险动作有独立语义。页面根据任务选用列表与详情、数据表、编辑器或画布加悬浮面板的布局。保留本项目自己的业务术语和功能，不照搬 RTLS 导航或演示数据。移动端、暗色模式和更大的触控目标需要另行设计。对于规范明确列出的当前差异，请采用其中的迁移建议，并说明偏离原因。

## 维护

这是对当前代码的整理快照，实际实现以 `lib/ui/` 和 `assets/map/` 为准。改变主题或共享组件后应同步参考包。原始设计稿在 `.design/`，早期开发说明在 `docs/development/`；它们与当前实现冲突时，以当前代码为依据。

在仓库根目录执行 `./docs/design/export-design-tokens.ps1` 可更新 JSON/CSS。字体、组件行为和密度条件属于人工核对快照，相关代码变化时需要同步脚本中的快照节与规范。
