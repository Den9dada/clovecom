# CloveCOM 桌面 GUI 迁移说明

本次以 `gui-style-reference.md`、`design-tokens.json` 与控件状态截图为视觉依据。公共主题在 `lib/ui/desktop_theme.dart`，普通动作高 28、行内动作高 24，控件/卡片/弹窗圆角为 6/8/12；品牌紫、语义状态、透明边框与叠加色按参考令牌定义。Material 3 保留作为现有控件宿主，实际动作状态由共享样式解析，避免仅依靠种子色。

## 业务布局

保留串口通信、USB通信、网络通信、工具箱、CH34x调试五个入口与实际模型数据。通信页沿用配置与收发工作区；CH34x 沿用寄存器列表、属性、批量操作与日志；工具箱沿用文件列表、二进制编辑器/片段布局和状态面板。没有新增 RTLS 导航、地图或演示设备。

## 参考差异的处理

| 参考差异 | 迁移结果与偏离原因 |
| --- | --- |
| 原始设计稿字体与 Flutter 不一致 | 注册现有 `assets/fonts/MiSans` 的 400/500/600/700；全局普通文字使用 MiSans。用户提到的 `assert/font` 在仓库中不存在。未发现等宽字体文件，数据使用 Consolas，回退 Menlo/Courier New/MiSans；最后的中文回退不保证等宽，后续提供字体文件时应随包注册。 |
| WebView 字体、画布网格与选中绘制不同 | 项目没有参考包中的 WebView 地图；不移植对应绘制路径，也不声称像素一致。二进制编辑器保留自己的选择与编辑语义。 |
| 品牌禁用令牌与实际灰底不同 | 采用实际灰底和灰字，禁用优先于按下、悬停与选中。 |
| 危险选中紫底红字 | 危险动作保持红底红边语义；键盘焦点独立显示紫色边框。 |
| CSS 额外令牌与局部尺寸不同 | 28/24 动作与 6/8/12 圆角作为共享规格；终端行高、Hex 字符网格和寄存器位格继续作为业务局部尺寸，避免破坏数据对齐。 |
| 旧截图与路由说明落后 | 以 CloveCOM 五个真实入口为准，参考截图仅用于视觉。 |
| 提示与焦点不一致 | 保留现有窗口按钮 Tooltip，解除根层对方向键焦点的屏蔽；共享图标动作要求可访问名称，所有动作包含焦点边框。 |
| 仅紧凑桌面，无移动/暗色规范 | 页面采用共享浅色主题。移动端、完整暗色主题及触控目标未另行设计。 |

导航按宽度 <1280 或高度 <720 收为 56 宽图标轨道，常规导航宽 200。首选窗口采用 1440×900；最小窗口保持项目已有 1240×860，而非参考的 1120×640，因为通信页配置区和已有固定面板尚未完成更小窗口的重排。全局状态栏保留项目自己的结构与通信状态语义。

`DesktopAction` 提供忙碌指示、防重复点击、纯图标名称与行内尺寸；已接入 CH34x 批量操作。现有业务的失败、输入保留、取消和持续错误逻辑仍由各 ViewModel 管理；不能将新增样式视为所有异步弹窗生命周期均已重写或完整无障碍审计。

## 验证说明

动作状态、忙碌防重入、导航与工具箱回归通过。真实 MiSans/Material 图标与 Windows Consolas 加载后的五页截图测试通过，修复 CH34x 速率下拉溢出。截图位于 clovecom-screenshots，属于 Widget 渲染，实际 Windows 宿主与高 DPI 仍需核验。静态检查没有编译错误；项目已有 CH34x 等模块警告保留。
